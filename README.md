## Project Goal

Our goal is to develop a functional predictive AI solution that:

1. Identifies a meaningful real-world problem
2. Uses available data to predict potential risks or outcomes early
3. Presents the prediction clearly to the user
4. Helps the user decide what action to take based on the prediction
